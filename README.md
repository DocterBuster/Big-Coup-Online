# Big Coup Online
When just regular Coup is not Big enough


# How to Contribute

1. Download Godot Engine 4.7
2. Create a branch from Dev to work on contnet
3. Submit a PR back to Dev! 


# About Big Coup
Big Coup is a game created during the Summer Internship Program at Mass Digi by Team AllyCats. It is a modification of the strategy card game "Coup" but is considered "Big" by the inclusion of additional cards, mechanics and Bigness not present in the original game.
